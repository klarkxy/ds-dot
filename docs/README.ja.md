# ドロシー（dot）

[English](../README.md) · [简体中文](README.zh-CN.md)

![スーツケースと傘を手に到着し、プロジェクトの調整を始めるドロシー](images/dot-arrival.png)

ドロシー（`dot`）は、DeepSeek Harness（DSH）向けの常駐コーディネーターです。専用サイドバーパネルで話しかけるだけで、ワークスペースの管理、複数セッションをまたいだタスクの割り当てと進捗追跡、定型的な承認や質問への対応、リマインダーの設定、さらにペルソナやあなたへの呼び方のカスタマイズまでまとめて任せられます。

## インストール

DSH `0.2.2-rc.3` 以降が必要です。利用しているプロファイルに追加してください：

```sh
dsh plugin --profile web add ds-dot
```

再起動を求められた場合はプロファイルを再起動してください。プレリリース版を使う場合は `ds-dot@next`、バージョンを固定する場合は `ds-dot@<version>` を指定します。

インタラクティブカードは Deep View 同梱のため、インストール後すぐに動作します。必要に応じて次の補助プラグインも併用できます：

- `@klarkxy/dsh-dev-index`：DSH ドキュメントとプラグインの検索
- `@klarkxy/dsh-model-picker`：設定画面での検索可能なモデルピッカー

## 日常的な使い方

サイドバーの **プラグイン** と **自動化** の隣にある **ドロシー** を開き、テキストや画像（PNG、JPEG、WebP、GIF 対応）でやりたいことをそのまま伝えます：

```text
D:\work\site にワークスペースを作成し、ドキュメントページのリンク切れを修正して。変更内容も教えて。
```

- **タスクの委任と舵取り：** ドロシーは通常の DSH セッションを起動してタスクを割り当てます（作業パスが競合しない場合は並列実行します）。完了報告をそのまま鵜呑みにせず、納品ファイルをあなたの要件と照合して検証してから報告します。実行中でもいつでも文脈を補足したり、要件を調整したり、一時停止・キャンセルしたりでき、完了処理の前に自分で結果を確認するよう求めることもできます。

- **承認と質問の代理対応：** 監視対象は「ドロシーが割り当てたタスクのみ」または「すべての DSH セッション」から選べます。既定値は `approvals=dot` と `questions=dot` です。目標の範囲で可逆な承認と質問は、合意・履歴・調べられる環境を確認したうえで彼女が決めます。ワークスペース外の削除、プッシュ、課金、認証情報、または途中で切れた承認はあなたへ強制され、彼女はその門を越えられません。どちらかの設定をあなた側にすると一件ずつ転送され、質問は元のセッションに残すこともできます。それでも質問するときは推奨を一つ添え、沈黙を同意とは扱いません。質問をあなたまたはセッションに任せた場合は、元のセッションで直接答えてください。

- **セッションの監視と履歴の検索：** 手動で開いた既存セッションの監視や、進行中の全タスクの確認、過去の会話やセッションの検索も頼めます。

- **リマインダーの設定：** 「30 分後に確認して」「毎朝平日の 9 時に夜間ビルドをまとめて」といった自然な言葉で登録できます。リマインダーは会話のセグメント引き継ぎや DSH の再起動をまたいで保持されます。

ドロシーは常にあなたの言語でやり取りしつつ、成果物はあなたまたはプロジェクトが使っている言語に合わせて作成します。会話が長くなると、進行中のタスク・リマインダー・記憶を保ったまま自動的に新しい **セグメント** へ引き継がれます。

## パネルと設定

### タスク

パネル上部の **タスク** を開くと、*すべて*・*要対応*・*進行中*・*監視・リマインダー* で絞り込めます。納品ファイルやチェック結果のメモを確認したり、レビュー待ちの作業を受け入れ・差し戻ししたり、関連セッションへ直接移動したり、不要なリマインダーを削除したりできます。

### 設定

パネル右上の歯車アイコンから **設定** を開きます：

- **ドロシーのモデル** と **バックグラウンド振り返り** のオン／オフを設定します。
- **セッション引き受け** で *対象範囲*、*権限の承認*、*モデルからの質問*、*タスク権限* を構成します。
- **割り当てタスク** で *使用可能なタスクモデル* と待機中の *定期チェック* 間隔（`0` でオフ）を設定します。
- 各項目には鍵アイコンがあります。ロックするとドロシーからの変更提案を禁止でき、ロック解除中は承認を前提とした変更提案を提出できるようになります。

さらに DSH プラグイン設定から、`homeDir`（ドロシー専用のワークスペースとセッションの保存先フォルダ。空の場合は DSH ホーム配下の `dot` フォルダを使用）および `approvalGraceMs`（承認通知の猶予時間、デフォルト `10000` ミリ秒。この時間内に元のセッションで完了した承認はドロシーを起動しません）を任意で調整できます。

### ペルソナ

**ペルソナ** タブでは、あなたへの呼び方や性格・話し方をカスタマイズし、長期記憶を管理できます：

- **取り決め：** あなたが定めたルールをそのままの言葉で保持します。常に認知よりも優先され、前回の保存を取り消すこともできます。
- **認知：** ドロシーが作業スタイルについて記録したメモです。直接編集したり、履歴バージョンを確認して元に戻したりできます。

### コンテキストと実行軌跡

- **コンテキスト：** トークン使用量、**プロンプトセクション**、キャッシュ統計を確認し、必要に応じて手動で新しい **セグメント** を開始できます。
- **実行軌跡：** ターンごとのステップ、ツール呼び出し、バックグラウンド振り返りの記録を検索・確認できます。

### 出荷時設定にリセット

設定画面の下部から、消去内容をプレビューしたうえでドロシーの作業履歴、彼女が開いたセッション、リマインダー、取り決め、認知、設定を初期化できます。あなた自身のセッション、プロジェクトファイル、およびホストのペルソナはそのまま残ります。

## ご利用にあたって

- 書き込み範囲はドロシーが割り当てたタスク同士を調整するためのものであり、外部エディタや他プロセスをロックするものではありません。
- 読み取り専用タスクの制限にはホスト側の強制適用が必要です。
- タスク結果の受け入れはタスクを完了状態にするだけであり、それ単体でプッシュ・公開・課金を許可するものではありません。
