# 桃乐丝（dot）

[English](../README.md) · [日本語](README.ja.md)

![桃乐丝带着行李和雨伞抵达，准备帮你协调项目](images/dot-arrival.png)

桃乐丝（dot）是 DeepSeek Harness（DSH）的常驻调度管家。在她的面板里直接对话，就能管理工作区、跨会话分派并推进任务、代管常规审批与提问、设置提醒，并自定义她的人设与对你的称呼。

## 安装

需要 DSH `0.2.2-rc.3` 及以上版本。将插件安装到你正在使用的 profile：

```sh
dsh plugin --profile web add ds-dot
```

DSH 提示时重启 profile。如需安装预发布版，可用 `ds-dot@next`；如需指定版本，可用 `ds-dot@<version>`。

交互卡片已内置 Deep View，安装后开箱即用。按需还可加装以下可选插件：

- `@klarkxy/dsh-dev-index`：查阅 DSH 文档与检索插件
- `@klarkxy/dsh-model-picker`：在设置页中搜索模型

## 日常使用

从侧栏「插件」「自动化任务」旁打开 **桃乐丝**，即可在她的独立对话面板中发送文字或附图（支持 PNG、JPEG、WebP、GIF）下达需求：

```text
在 D:\work\site 建个工作区，修好文档页里失效的链接，做完告诉我改了什么。
```

- **派发与推进任务**：桃乐丝会分派普通 DSH 会话去执行任务；当多个任务修改互不冲突的路径时，她会并行推进。收口前她会依据交付文件与你的要求核验结果，而不是轻信会话自报完成。途中可随时补充说明、调整要求、暂停或取消，也可以要求先过目再收口。

- **代管审批与提问**：你可以只接管她派出的任务，或接管所有 DSH 会话。默认情况下，常规请求会自动放行；涉及工作区外删除、推送、花钱或凭据的高风险审批，以及涉及方向或范围变更的提问，都会以卡片形式交由你决定。当提问交由你或原会话处理时，请在原会话中直接作答。

- **关注会话与检索历史**：你可以让她关注你手动开启的会话、巡检当前所有进行中的任务，或检索过往对话与历史会话。

- **定时提醒**：用自然语言设置提醒，例如「半小时后检查」或「每个工作日早上九点汇总进度」。提醒会跨对话分段与 DSH 重启持久保留。

桃乐丝始终使用你的语言向你汇报，同时让交付物沿用你指定的语言或项目原有语言。当对话较长时，她会自动交接至新的 **分段**，完整保留进行中的任务、提醒与记忆。

## 面板与设置

### 任务

点击面板顶部的 **任务** 打开任务抽屉，可按 *全部*、*待你处理*、*进行中*、*关注与提醒* 筛选事项：

- 查看交付文件与检查说明，接受或退回待验收工作。
- 跳转至对应的底层会话，或移除不再需要的提醒。

### 设置

点击面板右上角齿轮打开 **设置** 抽屉：

- 配置 **桃乐丝的模型** 与 **后台反思** 开关。
- 在 **会话接管** 下配置 *接管范围*、*权限审批*、*模型提问* 与 *任务权限*。
- 在 **派发任务** 下配置 *可用模型范围* 与 *例行检查* 间隔（设为 `0` 则不检查）。
- 每项设置旁都有锁图标：锁定后禁止她提议修改；未锁定时她可提交修改提案，由你批准后应用。

此外，在 DSH 插件配置中还可按需设置 `homeDir`（桃乐丝自己工作区与会话的目录，留空默认使用 DSH 主目录下的 `dot` 文件夹）和 `approvalGraceMs`（审批通知宽限期，默认 `10000` 毫秒；期间在原会话结算的审批不会唤醒桃乐丝）。

### 人设

在 **人设** 标签页中自定义桃乐丝对你的称呼与性格说话方式，并管理长期记忆：

- **约定**：以你的原话保留常驻规矩，与认知冲突时一律以约定为准，支持回退上次保存。
- **认知**：记录桃乐丝对协作偏好与节奏的理解，可直接编辑，也可查看并恢复历史版本。

### 上下文与轨迹

- **上下文**：查看当前 Token 用量、**提示词分区** 与累计缓存统计，或手动开启新的 **分段**。
- **轨迹**：按轮次搜索对话步骤、工具调用与后台反思记录。

### 出厂设置

位于设置页底部，可先预览再清除桃乐丝的工作记录、她创建的会话、提醒、约定、认知与设置，保留你自己的会话、项目文件与宿主人格。

## 使用须知

- 写入范围仅用于协调桃乐丝派出的任务，不会锁定外部编辑器或其他进程。
- 只读任务需要宿主环境强制执行权限。
- 接受交付仅完成任务收口，不代表授权推送、发布或花钱。
