# 桃乐丝（dot）

[English](../README.md) · [日本語](README.ja.md)

![桃乐丝带着行李和雨伞抵达，准备帮你协调项目](images/dot-arrival.png)

桃乐丝（`dot`）是 DeepSeek Harness（DSH）的常驻调度管家。在侧栏专属面板中直接和她对话，就能管理工作区、跨会话派发并核验任务、代管常规审批与提问、设置定时提醒，还能自定义她的人设与对你的称呼。

## 安装

需要 DSH `0.2.2-rc.3` 及以上版本。将插件添加到你正在使用的 profile：

```sh
dsh plugin --profile web add ds-dot
```

按提示重启 profile 即可生效。预发布版可使用 `ds-dot@next`，锁定版本可使用 `ds-dot@<version>`。

交互卡片已内置 Deep View，安装后开箱即用。按需还可搭配以下可选插件：

- `@klarkxy/dsh-dev-index`：检索 DSH 官方文档与插件仓库
- `@klarkxy/dsh-model-picker`：在设置页提供可搜索的模型选择器

## 日常使用

从侧栏「插件」「自动化任务」旁打开 **桃乐丝**，在独立对话面板里发送文字或附图（支持 PNG、JPEG、WebP、GIF）交代要办的事：

```text
在 D:\work\site 建个工作区，修好文档页里失效的链接，做完告诉我改了什么。
```

- **派发与推进任务**：桃乐丝会启动普通 DSH 会话执行具体工作；当不同任务修改的路径互不重叠时，她会自动并行推进。收口前她会对照需求场景逐项核验交付文件与证据，而非轻信执行会话自称完成。任务进行中可随时补充背景、修改要求、暂停或取消，也可以要求由你亲自过目后再收口。

- **代管审批与提问**：可选择只接管她派出的任务，或接管全部 DSH 会话。默认启用 `approvals=dot` 与 `questions=dot`：目标范围内常规、可逆的选项，她会先核对约定、历史对话与工作区现状后自行决定，已获授权的操作不会重复打扰。把握再大的猜测也不能替代缺失的授权；涉及不可逆、外部影响或产生费用的操作仍须具备明确授权。代码层（`src/approval-risk.ts` 中的 `approvalNotice`）还设有一道硬性兜底：一旦审批展示内容被截断，或 `assessApprovalRisk` 命中高危模式（沙箱提权、发布/推送命令、递归删除、私钥/凭据读取、子代理 Shell 调用、只读运行尝试写入等），系统将强制交由你本人确认，桃乐丝无法越过。由于静态规则仅覆盖特定高危模式而非所有删除、密钥读取、写入或花销，其余请求仍由她结合授权边界与后果审慎判断。需要请示你时，她会附上一项明确建议，且绝不把沉默当成同意。将审批切换为「用户管」会逐条转交审批卡片；将提问设为「一律转问我」或「不接管」时，请在原会话中直接作答。

- **关注会话与检索历史**：可以让她跟进你手动开启的会话、巡检当前所有运行中的任务，或检索过往分段与任务会话的完整记录。

- **定时提醒**：直接用自然语言设置单次或周期提醒（如「半小时后看下测试结果」「每个工作日早上 9 点汇总过夜构建」）。提醒会跨对话分段与 DSH 重启持久保留。

桃乐丝始终用你的语言向你汇报，同时让代码、文档等交付物遵循你指定的语言或项目原有语言。长对话接近上下文阈值时会自动交接至新 **分段**，完整保留在途任务、提醒与长期记忆。

## 面板与设置

### 任务

点击面板顶部的 **任务** 打开任务抽屉，可按 *全部*、*待你处理*、*进行中*、*关注与提醒* 筛选：

- 查看交付文件变更与核验记录，接受或退回待验收工作。
- 一键跳转到底层执行会话，或移除不再需要的提醒。

### 设置

点击面板右上角齿轮打开 **设置** 抽屉：

- 配置 **桃乐丝的模型** 与 **后台反思** 开关。
- 在 **会话接管** 下配置 *接管范围*、*权限审批*、*模型提问* 与 *任务权限*。
- 在 **派发任务** 下配置 *可用模型范围* 与空闲时的 *例行检查* 间隔（设为 `0` 关闭巡检）。
- 每项设置旁均配有锁形开关：锁定后禁止桃乐丝提议改动；解锁时她可提交修改提案，经你批准后才会生效。

此外，在 DSH 插件配置中还可按需设置 `homeDir`（桃乐丝专属工作区与会话目录，留空默认使用 DSH 主目录下的 `dot` 文件夹）与 `approvalGraceMs`（审批通知宽限期，默认 `10000` 毫秒；在此期间已于原会话处理的审批不会唤醒桃乐丝）。

### 人设

在 **人设** 标签页自定义桃乐丝对你的称呼与说话风格，并管理双层记忆：

- **约定**：按你的原话保存常驻规矩，与认知冲突时一律以约定为准，支持一键回退上次保存。
- **认知**：记录桃乐丝对协作节奏、偏好与共同经历的理解，可直接编辑，也可随时查看并恢复历史版本。

### 上下文与轨迹

- **上下文**：查看当前 Token 占用、冻结的 **提示词分区** 与累计缓存命中率，或手动开启新 **分段**。
- **轨迹**：按轮次检索对话步骤、工具调用参数及后台反思记录。

### 出厂设置

位于设置页底部，可先预览清除范围，再一键清空桃乐丝的工作记录、她创建的会话、提醒、约定、认知与设置；你本人的会话、项目文件与宿主人格均不受影响。

## 使用须知

- 写入范围用于协调桃乐丝派出的并发任务，不会对外部编辑器或系统进程加锁。
- 只读任务的沙箱边界依赖宿主环境权限控制与工具预执行拦截共同保障。
- 接受交付仅代表完成当前变更验收，本身不构成对推送代码、发布包或付费操作的授权。
