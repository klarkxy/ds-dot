# 桃乐丝（dot）

<!-- release-state-note -->

[English](../README.md)

DeepSeek Harness 的常驻调度管家桃乐丝，简称 dot。在她自己的面板里和她对话：她管理工作区、启动任务、跟进进度、处理审批，并向你汇报。你只需要在一个对话里交流，而她负责调度你的项目。

她的聊天风格轻松且真诚。工作进行时，她会保持任务推进并提供清晰的进度更新。你可以在设置里自定义她的人设和称呼。

## 安装

从 GitHub 装进你正在用的 profile：

```sh
dsh plugin --profile web add github:klarkxy/ds-dot
```

pnpm 默认不会构建 Git 依赖。如果第一次安装停下来，把终端里打印的包名写进该 profile 的 `pnpm-workspace.yaml`：

```yaml
allowBuilds:
  "@klarkxy/dsh-dot": true
```

再执行同一条 `dsh plugin add`。DSH 提示时重启 profile。想固定这次版本时，钉住提交：`github:klarkxy/ds-dot#<commit>`。

包名仍是 `@klarkxy/dsh-dot`。Deep View 会一起装上，负责绘制卡片、确认框和图表。

## 使用

点侧栏「插件」「自动化任务」那一列里的 **桃乐丝**。当面板打开时，她的鲸鱼图标会变为粉色。该面板是她的专属对话环境，独立于你的工作区会话列表。

直接告诉桃乐丝你要做什么，例如：

```text
在 D:\work\site 建个工作区，开一个任务：修好文档页里失效的链接，做完告诉我改了什么。
```

桃乐丝将你的请求转换为任务并开始工作。对于明确的任务，她直接执行；对于复杂任务，她会创建一个草稿供你审核。她的管理方式如下：

- **工作区管理**：她新建或复用工作区，为每个任务写好完整的第一条指令。同一任务可先后关联独立的执行、验收和返工会话。
- **资源协调**：她管理目录的写入权限，保持你的项目井井有条。
- **代理选择**：她为任务挑选合适的预设：通用任务用默认预设，脚本任务用 `ptc`，插件开发任务用 `cordis`。
- **专属环境**：她维护一个自己的工作区用于调研或 DSH 管理任务，通过 DSH 主目录下的 `dot` 文件夹访问。
- **会话跟踪**：她可以按你的指示启动、停止或关注会话。
- **智能更新**：她汇总任务动态、审批与提问，并在空闲时高效送达。
- **审批管理**：她接管所有会话的审批请求，常规审批自动完成，涉及高风险变更（如删除外部数据、发布、推送、范围变更）时会通过卡片征求你的意见。

桃乐丝的每一次交互都以一张卡片结束。报告用展示卡呈现文字、表格或图表；需要决策时，交互卡提供选项、确认按钮或表单。

点击面板顶部的「任务」即可打开任务看板。你可以查看「等你处理」「进行中」「待办」等状态，点击任务行查看目标、验收标准与流转记录，或管理草稿。等你验收的任务点击「通过」即可完成，点击「打回」可添加反馈意见。

她还能处理定时提醒。你可以要求她「半小时后提醒我」或「每个工作日早上九点汇总进度」。这些提醒在对话分段、会话重启甚至 DSH 重启后依然生效。

## 设置

点击齿轮图标打开包含「设置 / 人设 / 上下文 / 轨迹」的抽屉。你可以个性化调整她的模型、审批习惯、任务权限以及性格。

- **人设**：自定义称呼与语气。
- **约定**：记录你的常驻要求与规矩。
- **认知**：桃乐丝对你的理解，随协作自动更新。
- **上下文**：查看当前分段的 Token 用量与提示词组成。

## 限制

- **工作流整合**：桃乐丝通过任务会话操作，所有 shell 与文件操作均有记录可查。
- **资源覆盖**：她的搜索限于她自己的对话记录和她所管理的任务会话。
- **约定与认知**：通过「人设」页管理，确保你的偏好得到尊重。
- **任务看板**：提醒管理统一在她的任务板上进行。
- **审批路由**：用户审批模式下，请使用对应请求的确认卡；过期卡片不能批准后来的请求。
- **用户答复提问**：用户答复提问模式下，请在原会话中回答原始问题。
- **后台回复**：后台回合结束时如果没有可用卡片，普通文本仍会显示。
- **任务权限**：宿主无法强制只读权限时，只读任务不会启动。运行中的任务在当前权限可核验时可接收补充要求；否则须先停止会话并应用当前权限，才能继续。
- **取消任务**：确认关联会话停止之前，任务会继续持有目录锁。
