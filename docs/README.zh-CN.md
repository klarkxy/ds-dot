# 桃乐丝（dot）

[English](../README.md)

![桃乐丝带着行李和雨伞抵达，准备帮你协调项目](images/dot-arrival.png)

桃乐丝（dot）是 DeepSeek Harness 的常驻调度管家。在她自己的面板里对话：她管理工作区、启动会话、跟进进度、处理审批，并向你汇报。人设和称呼都可自定义。

## 安装

需要 DSH 0.2.2-rc.3 或更高版本。装进你正在用的 profile：

```sh
dsh plugin --profile web add ds-dot
```

DSH 提示时重启 profile。用 `ds-dot@0.2.0` 固定这一版，或用 `github:klarkxy/ds-dot#<commit>` 安装源码修订。Deep View 随包安装，负责卡片展示。可选的 `@klarkxy/dsh-dev-index` 提供文档和插件检索，`@klarkxy/dsh-model-picker` 为设置提供模型搜索。

本地开发：

```sh
dsh plugin --profile web add link:H:\Code\ds-dot
pnpm watch
```

链接安装包含 `src`，watch 会随编辑重建 `lib`。源码安装若需要构建许可，在该 profile 的 `pnpm-workspace.yaml` 中允许 `ds-dot` 后重试安装。

## 使用

从侧栏「插件」「自动化任务」旁打开 **桃乐丝**，面板有独立的对话。直接告诉她要做什么：

```text
在 D:\work\site 建个工作区，修好文档页里失效的链接，做完告诉我改了什么。
```

桃乐丝把每个目标记为变更，附上要求，交给普通会话执行：

- **工单**：每个目标成为一个变更：原样保留你的原话，要求逐条编号并各带具体的检查场景（WHEN … THEN …），做法上的约束也逐条编号，步骤可选并注明它服务哪条要求。同一件事只写一次，其他地方按编号引用。
- **进度与完成**：步骤是进度笔记。是否完成由逐项要求检查决定；没有列出要求时，也需要明确的目标检查。会话自称「完成」不会让变更收口。
- **写入范围**：分派时预约范围并保存开工前状态。交付只在各次写入范围的并集内比较，范围外的观察另行报告。互不冲突的会话可以并行；确认会话及其作业停止后才释放范围。
- **收口**：默认直接收口。桃乐丝记录逐项结论、检查说明和证据引用，采集交付并核验后接受。可选独立审查，审查结束后可收口或退回返工。旧版保存的证据文件仍能读取。
- **开工指令**：每个 Run 的第一条消息由工单生成，包含目标、你的原话、范围、要求与场景、约束、它负责的步骤和固定的回报格式；桃乐丝只补充背景说明，所以 Run 读到的条款和检查用的是同一份。Run 自己说「通过」不算结论。
- **工作语言**：代理之间的工单、指令和回报一律用英文，以保证指令遵循稳定。你的原话、精确字符串、文件内容和引用文字原样保留、绝不翻译；交付物用你指定的语言，没指定就沿用项目已有的语言。给你看的内容一律跟随你的语言。
- **后续指令**：改变要求会生成新输入版本；补充上下文按当前版本向活动会话投递一次。暂停阻止新会话启动；取消会先收拢活动会话，再释放范围。
- **人工决定**：你要求先过目时，她等待对应版本的决定。过期卡片和旧决定不能批准后续工作。旧版工单保留为只读历史。

顶部 **任务** 打开看板，展示进度、会话、占用者、检查与收口操作。展开检查可读说明或引用，也可查看交付文件；长内容提供预览和全文。内部 ID 仅在 **诊断** 中显示。检查和资源清理确认后，变更才显示 **已完成**。

桃乐丝也会关注你指定的会话，汇总审批和提问。按设置处理的常规请求可静默结算，需要你决定时会显示卡片。用户答复提问模式下，请在原会话中回答。

你可以要求「半小时后检查」或「每个工作日九点汇总进度」。提醒会跨对话分段和 DSH 重启保留。

## 设置与限制

齿轮打开设置、人设、上下文和轨迹。**约定** 保存你的常驻规则，**认知** 保存桃乐丝对协作方式的理解。恢复出厂设置会清除她的工作记录、她创建的会话、提醒和设置，保留你自己的会话与项目文件。

写入范围用于协调分派，不会阻止外部编辑器或进程。只读会话需要宿主强制执行权限。过期输入会被拒绝，无法确认停止时继续占用范围。接受交付本身不授权发布、推送或花钱。

工作模型已有单元、UI 层和隔离宿主测试覆盖。真实多会话协作、浏览器看板及完整模型驱动行为仍在验证中。
